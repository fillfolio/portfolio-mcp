Standalone skill ZIP links and hashes appear in the workflow catalog. The release checksum file uses skills/<name>.zip paths; GitHub serves those standalone files by their basename. Match the basename and digest when downloading one file.

Verify a selected download with your operating system's SHA-256 utility. On macOS:

shasum -a 256 fillfolio-portfolio-overview.zip

Compare the result with the exact hash listed for that file. A checksum verifies file identity; it does not establish host OAuth compatibility.

Machine-readable documentation¶

llms.txt lists the documentation and source links. llms-full.txt includes the authored pages and generated references. These files provide text for readers and agents; they do not install a connection or guarantee search indexing.

Support and contributions¶

Use portfolio-mcp issues for contract/docs reports and portfolio-mcp-skills issues for workflow reports. Do not post financial records or credentials in a public issue.

Public materials use MIT. Fillfolio operates the hosted service under separate terms and privacy disclosures.
